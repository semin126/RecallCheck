# RecallCheck - 암기 채점기

외운 문장을 얼마나 정확히 재현했는지 **편집 거리 알고리즘**으로 채점하는 웹 프로그램입니다.
외부 라이브러리 없이 HTML 파일 하나로 동작합니다.

👉 **[사용해보기 버튼](https://semin126.github.io/RecallCheck/)** 

---

## 왜 만들었나

암기 과목을 공부할 때 답을 써놓고 정답과 비교하는 일은 결국 사람이 눈으로 합니다.
"조사 하나 틀린 것"과 "핵심 단어를 통째로 빠뜨린 것"은 전혀 다른데,
스스로 채점하면 둘 다 대충 "맞은 셈"으로 넘어가기 쉽습니다.

RecallCheck는 이 판단을 계산으로 대신합니다. 
**AI가 아니라 알고리즘이 채점하므로, 같은 답에는 언제나 같은 점수가 나옵니다.**

## 주요 기능

| 기능 | 설명 |
|---|---|
| 문제 세트 | 앱에서 직접 만들거나, 텍스트·엑셀 파일로 불러오기 |
| 연습 | 플래시카드 / 문서 읽기 |
| 테스트 | 답을 타이핑하면 즉시 채점 |
| 오류 피드백 | 숫자·기호·핵심 요소·표현 차이를 구분해 알려줌 |
| 재시험 루프 | 틀린 문항만 다 맞힐 때까지 반복 출제 |
| 시험지 만들기 | 답안 포함본 / 답안 작성용을 인쇄·PDF·워드로 저장 |
| 사진 채점 | 손으로 푼 답안지를 옮겨 적어 채점 (외부 API 키 필요) |
| 기록 | 최근 3회 결과와 100% 달성 문항 표시 |

## 채점 원리

문자열 A(정답)를 문자열 B(내 답)로 바꾸는 데 필요한 **최소 편집 비용**을 동적 계획법으로 구합니다.

```
dp[i][j] = min(
  dp[i-1][j-1] + (같으면 0, 다르면 교체 비용),   // 바꿔 쓰기
  dp[i-1][j]   + 그 요소의 비용,                 // 빠뜨리기
  dp[i][j-1]   + 1                               // 덧붙이기
)
유사도(%) = (1 - 최소 편집 비용 / 정답 전체 비용) × 100
```

기본은 레벤슈타인 거리이고, 여기에 **가중치**를 얹었습니다.

| 요소 | 비용 |
|---|---|
| 문항에 지정한 핵심 요소 | 3 |
| 숫자 · 수학 기호 | 2 |
| 그 밖의 단어 / 글자 | 1 |

핵심 요소가 빠지면 유사도가 아무리 높아도 정답으로 처리하지 않습니다.
역추적으로 어느 자리를 고쳤는지 복원해 오류 종류(숫자 오류 / 기호 오류 / 표현 차이 / 낱말 오류 / 빠짐 / 군더더기)를 붙입니다.

### 분야별 기준

무엇을 외우는지에 따라 맞고 틀림의 기준이 다르므로, 세트마다 기준을 저장합니다.

- **일반 서술형** — 단어 단위, 구두점 무시
- **영어 단어·문장** — 대소문자·구두점 무시
- **수학·기호** — 글자 단위, 기호 구분, 기호가 틀리면 오답
- **법조문·경전** — 글자 단위, 정확한 재현 요구

## 문제 세트 만들기

앱 안에서 직접 입력하거나, 아래 두 형식의 파일을 올리면 됩니다.
`#`으로 시작하는 줄은 안내문으로 보고 무시합니다.

**빈 줄 구분 (.txt)**
```
3·1 운동의 의의를 서술하시오.
전 민족이 참여한 최대 규모의 독립운동이다.

세포막의 기능을 설명하시오.
물질의 출입을 조절해 내부를 일정하게 유지한다.
```

**탭 구분 (.tsv)** — 엑셀에서 A열 질문, B열 답안을 쓰고 "텍스트(탭으로 분리)"로 저장

## 파일 구조

```
index.html    프로그램 전체 (HTML + CSS + JavaScript, 외부 라이브러리 없음)
sets.json     처음 방문한 사람에게 보여줄 기본 세트 (선택)
```

## 데이터가 저장되는 곳

만든 세트와 기록은 **사용자 브라우저 안(localStorage)에만** 저장됩니다.
서버로 전송되지 않으므로 방문자끼리 데이터가 섞이지 않고, 반대로 브라우저를 바꾸면 따라가지 않습니다.
기기를 옮길 때는 홈 화면의 **모든 세트 내보내기 / 불러오기**를 쓰세요.

## 알아둘 점

- **사진 채점**은 손글씨를 글자로 바꾸는 단계에서 외부 AI 서비스를 부릅니다.
  API 키가 없으면 이 단계만 동작하지 않으며, 표에 직접 입력하면 채점은 정상 작동합니다.
- 유사도는 재현 정확도를 재는 값이지, 서술형 답안의 내용 타당성을 판단하지는 않습니다.
- 같은 뜻의 다른 표현(예: "조절한다" ↔ "통제한다")은 다른 것으로 봅니다.
